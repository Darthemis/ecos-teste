# Ecos do Último Éon — construção de teste

Este repositório contém **apenas a construção jogável**, para que quem testa
possa abrir um link. O código-fonte, o GDD e o Plano de Ação vivem noutro
repositório, privado.

`index.html` é autocontido: um único ficheiro, sem qualquer pedido externo.
Abrir localmente também funciona, sem servidor e sem internet. Requer WebGL2.
